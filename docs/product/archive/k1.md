## Goal
The page history (`product view`, History tab) shows the cost per changed code line next to the cost per changed file, and the sprint card shows the text of the decision-maker's questions instead of only their number. Context: `roadmapa-dwmt.md` step K1, `docs/zgloszenie-2026-10-20/bugs.txt` point 9.

## Acceptance
- AC-1 `scripts/lib/price.mjs#changedCodeFiles` (or a sibling next to it) also gives changed lines = added + deleted from the same `git diff --numstat` of the squash commit, for the same code files that are counted today; binary files (`-`) skipped as today. `completedRuns` returns `lines`; `.dwmt/price-cache.json` entries without lines are recomputed.
- AC-2 Lines are kept where files are kept today: `actual.lines` in the sprint file and a `lines` column in the archive index (`product-store.mjs`). Rows and sprint files without lines read as unknown, never as an error or zero. `product sync` fills lines for closed sprints whose squash commit is in the repo.
- AC-3 History tab: a KPI tile "cost per changed line" (median of the range, in thousand tokens per line), table columns Lines and Per line, lines in the chart tooltips, a file/line switch on the cost chart; every new string in PL and EN; a sprint without lines shows "—".
- AC-4 Sprint card, "From you" block: the list of the `[decision-maker]` open questions' text (from `userQuestions`, without `[architect]` lines), each as a bullet; a translation from the page's translation memory when it has one, else the original text.
- AC-5 Tests: lines from numstat incl. a binary file; history with and without lines; an old archive row without the column; questions listed in the card data.

## Out of scope
- Cost analysis scripts outside the plugin; the start price and estimates stay per file.
- Reading runs from the home tree instead of the first worktree (`mainTreeOf` in `completedRuns`): step K3.

## Decisions
- SD-1 A changed line = added + deleted lines in the code files already counted for "changed files" (user, 2026-10-21).
- SD-2 On the page per line is in thousand tokens; per file stays in M tokens.
- SD-3 Tests: run only the test files related to the change (e.g. `dwmt/test/view.test.mjs`, a `price` test); never the full suite `dwmt/test/*.test.mjs` (user, 2026-10-21: ~53 min, too expensive).
