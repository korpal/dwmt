## Goal
Deferred review findings stop being a dump without an owner: serious ones cannot be deferred as minor, a deferred major does not merge silently, every deferred finding has an owner, and the report says up front how many there are. Product-layer commits stop leaking into task diffs, and the product page is published with the product by default. Context: `roadmapa-dwmt.md` step K2, `docs/zgloszenie-2026-10-20/ideas.md` §0.5 and §0.6.

## Acceptance
- AC-1 Severity floor: a finding about data loss or deletion, acting outside its target (paths, directories), a false promise of a contract or docs, silently wrong results, or security is at least `major`; the pragmatism pass cannot lower it without a counter-proof `file:line`. In the reviewer's lens prompts and, where the review header allows, checked by the script.
- AC-2 A deferred `major` blocks `finish` until the user accepts it explicitly (the run stops with the list of those findings and one command or answer to accept them); `minor` as today.
- AC-3 Every deferred finding has an owner. With the product layer: a backlog item of type `remark` pinned to the source sprint. Without it: an entry in the deferred file with owner and date fields. The final report's first lines: "deferred N, of which M major", with the major ones listed.
- AC-4 The task diff (`diff.patch` and the review input) leaves out product-layer files and commits made by `product commit` during the run; files outside the task scope appear as names only.
- AC-5 `product.view.publish` defaults to `<product.dir>/roadmap.html` (the page is committed with the product); `null` turns it off; an explicit value in a config is kept.
- AC-6 Tests for each criterion, in the test files of the changed modules.

## Out of scope
- The home tree of a run (step K3); review rounds and reviewer effort (step K9).

## Decisions
- SD-1 Without the product layer the deferred list stays a file, with owner and date per entry; the product layer is not required (user, 2026-10-21).
- SD-2 The page is committed with the product by default (user, 2026-10-21; the size warning in ideas.md §0.6 was weighed).
- SD-3 Tests: run only the test files related to the change; never the full suite `dwmt/test/*.test.mjs` (user, 2026-10-21).
