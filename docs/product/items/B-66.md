Measure real work time, not sprint start to end. From the run's session transcripts (as `sessionsCost` in `dwmt/scripts/lib/live.mjs`) sum the intervals of model turns and of running tool calls. Leave out:
- waits for the user (AskUserQuestion, ask stops of the driver);
- gaps with no pending tool call above a cap (crash, hang, API error; e.g. 5 min);
- time between sessions.

Split the active time into model, tests (verify command `ms`, `lib/verify.mjs`) and machine queue wait (`~/.dwmt/queue.log`). Record it in the sprint `actual` at finish; show minutes per changed line next to tokens per changed line in the History tab (median, trend), so slow tests or long fix rounds show up. Backfill finished sprints where their transcripts remain (`sessions` in final reports).

Rough size: 8-13 files (live or a new time module, finish, product-view, view.js/css, tests, product-layer spec); price about 3-6 M in single mode (start-check at refinement gives the real one).
