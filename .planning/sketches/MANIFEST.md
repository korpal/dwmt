# Sketch Manifest

## Design Direction
Human projection of the dwmt product layer: one local HTML file generated by a dwmt script (0 tokens) from `docs/product/` (roadmap, sprint files, backlog, decisions, archive, estimates). Dense dashboard for quick insight, neutral and technical in the style of Jira / Azure DevOps / GitHub Projects; states and numbers read at a glance from colour and labels. First screen answers "where are we and what's next". Language from config `language` (fallback: the user's language), Polish and English supported for UI and content. Audience: the decision-maker, on a computer.

## Reference Points
- Jira / Azure DevOps: backlog with filters, board, delivery plan with dependencies.
- GitHub Projects: table view grouped by field, labels.

## Decisions (user, 2026-10-15)
- Board by state (001 B) is the base layout.
- Human states: **Draft** (an idea, not yet clear what it is) → **To do** (clear; ordered; the PO takes from the top and closes price, mockups and last questions when taking it; badge "can go without you" once ready) → **In progress** (ordered or running) → **Awaiting review** (UAT and/or reading the code before push, per project; the code-review gate itself is a separate dwmt change, open). Needs a dwmt state-model change (D4 §3.9).
- Dependency "X before Y" shown only on Y ("after: X") while X is not merged; no "related sprints" highlighting.
- The page is read-only; order changes only in conversation with the PO, which warns when a move breaks a dependency (script already rejects it).
- Sprint panel for humans: the PO writes a short section in the user's language; agents never get it; the rest is computed by the script.

## Data
Findings from an earlier product layer (2026-10-15): many sprints awaiting review, the oldest for over a week; open items still assigned to closed sprints, likely a `sync` gap; the start price held in about half of the sprints.

Data via `python data/build-data.py [project-root]` → `data/data.js`; the default root is this repo, so the data-driven sketches (001–004) show dwmt's own `docs/product/`. Optional hand translations in `data/pl.js` (stand-in for the translation memory) and PO texts in `data/human.js`. Generated and hand files stay out of git. Shared frame: `shared/app.css`, `shared/app.js`. View over HTTP: `python -m http.server 8765` in this directory, then `http://127.0.0.1:8765/<sketch>/index.html` (file:// also works in a normal browser).
