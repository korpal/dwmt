Screens against the agreed mockups (images, not code).
- blocker: the screen or a required element is missing, broken or unusable (overlap, clipped content, error or empty state instead of content).
- major: a structural deviation a user notices: an element missing or extra, a different order or grouping, a different component (table vs cards, tabs vs list), different label or action copy, the mockup's state not shown.
- minor: spacing, sizes, colours, font weight, icons, pixel alignment.
- Ignore the mockup's own variant bar and annotations, browser chrome and fixture data (names, amounts, dates).
- Say what the mockup shows and what the app shows in that region, quoting the visible text.
- Record each pair's risk in the header `risks`.
